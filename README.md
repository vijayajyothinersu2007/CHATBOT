# Full-Stack AI Chatbot Web Application

A clean single-page chat environment built using Flask, SQLite, and Google Gemini.

## 🛠️ Deploy Pipeline
1. Add your real key inside `.env` configuration rows: `GEMINI_API_KEY=AIzaSy...`
2. Run installation rules: `pip install -r requirements.txt`
3. Execute the launcher script: `python app.py`
